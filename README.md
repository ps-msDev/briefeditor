# 📝 BriefEditor

> **A modern, privacy-focused letter editor for DIN 5008 compliant business correspondence**

[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

## ✨ Features

- 📋 **DIN 5008 Compliant** - Follows German business letter standards
- 🔒 **Privacy First** - No data collection, everything runs locally
- 🎨 **Modern UI** - Clean, responsive design with real-time preview
- 📱 **Mobile Friendly** - Works seamlessly on all devices
- 🌍 **Multilingual** - German and English support
- 📄 **PDF Export** - Generate professional PDFs instantly
- 🖨️ **Print Ready** - Optimized for printing and digital distribution
- ⚡ **Fast & Lightweight** - Built with modern web technologies

## 🚀 Quick Start

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/ps-msDev/briefeditor.git
cd briefeditor

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173` to see the application.

### Building for Production

```bash
npm run build
```

## 📋 DIN 5008 Compliance

This editor follows the German DIN 5008 standard for business correspondence, ensuring your letters meet professional requirements:

- ✅ Proper margins and spacing
- ✅ Correct sender/recipient formatting
- ✅ Standard date and subject line placement
- ✅ Professional closing and signature areas
- ✅ Optional fold marks and hole punch guides

## 🔒 Privacy & Data Protection

- **No Data Collection** - Your letters never leave your device
- **No Tracking** - No analytics or user tracking
- **Local Processing** - Everything runs in your browser
- **GDPR Compliant** - No personal data storage
